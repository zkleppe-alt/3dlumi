Kingdom's Last Knight

Download the launcher to play offline on your own computer. Your saves stay on your computer, and the game only updates when you click Update.

🪟

Windows

Windows 10 or 11. Run the installer; if SmartScreen says "Windows protected your PC", click More info → Run anyway.

Download for Windows
🍎

Mac

macOS 11 or later, Intel or Apple silicon. Open the .dmg and drag the launcher to Applications.

Download for Mac
"Can't be opened" the first time?
  1. In Applications, right-click (or Control-click) Last Knight Launcher.
  2. Choose Open, then Open again. You only need to do this once.
🐧

Linux

An AppImage for most desktops, Steam Deck desktop mode included.

Download for Linux
How to run it
  1. Right-click the file → Properties → allow running as a program (or chmod +x).
  2. Double-click to start.
💻

Chromebook

Chromebooks install the game as an app from Chrome. Installed, it plays offline and keeps your version until you tap Update now.

Open the game
How to install
  1. Open the game in Chrome.
  2. Click the install icon at the right of the address bar, or ⋮ → Cast, save and share → Install page as app.
  3. Open Last Knight from your app launcher from then on.

Update when you choose

When a new version is out, the launcher shows what's new and the size of the download. Nothing changes until you click Update, and only the changed files come down.

Your saves are safe

Your saves are backed up before every update. Back them up, restore them or export them to a file from the launcher's Saves page.

Bring your browser saves

In the game in your browser: ☰ → System → Export saves. Then in the launcher: Saves → Import a backup.
