Vanquish (Dark Ages playtest v0.1) — a chess-like strategy game by theoriginalkarl (https://theoriginalkarl.itch.io/vanquish-the-dark-ages),
a friend of Zak's, included in Kingdom's Last Knight with permission. Unmodified build from itch.io. Played at the war table in Ironhold Keep
(engine/vanquish.js opens it in a frame). It keeps its own online play (its maker's server: anonymous sign-in, matches, ladder, tournaments,
chat, finished games recorded for balance tuning) — Zak chose to keep that as-is (V290).
